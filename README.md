# claude-statusline

Claude Code status line: `user@host:cwd | model (effort) | ctx % | $cost | 5h % 7d %`

Install on a machine (needs jq and bash):

    git clone https://github.com/ruserxd/claude-statusline.git ~/claude-statusline && ~/claude-statusline/install.sh

Update: `cd ~/claude-statusline && git pull` (the symlink picks it up; restart Claude Code).
